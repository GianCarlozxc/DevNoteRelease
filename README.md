# DevNote

A Windows desktop notepad with app-only notes, collections, checklists, reminders, and customizable typing animations.

Download [DevNote 1.3.0](https://github.com/GianCarlozxc/DevNoteRelease/releases/tag/v1.3.0):

- [Windows x64 installer](https://github.com/GianCarlozxc/DevNoteRelease/releases/download/v1.3.0/DevNote-Setup-1.3.0-x64.exe)
- [Windows x64 portable ZIP](https://github.com/GianCarlozxc/DevNoteRelease/releases/download/v1.3.0/DevNote-1.3.0-windows-x64.zip)
- [SHA-256 checksums](https://github.com/GianCarlozxc/DevNoteRelease/releases/download/v1.3.0/SHA256SUMS.txt)

Run the installer, or extract the entire portable ZIP and run DevNote.exe. Keep the other extracted files beside it. Node.js is not needed.

Install the latest version once if you are using 1.0.0. Version 1.1.0 or newer can update inside the app. Future versions can be downloaded from Settings using Check for updates, Download update, and Restart to update. Unsaved notes must be saved before restarting.

Your notes stay in DevNote's local AppData storage. Keep the app running or minimized for scheduled reminders. This release is not digitally signed.

This release is provided for manual testing. Automated tests and application runtime checks were not run, as requested.

See [release notes](RELEASE_NOTES.md) for features and manual testing status. Application source is maintained separately in the private [DevNote repository](https://github.com/GianCarlozxc/DevNote), tagged v1.3.0. Source commit: aaf7ad6.
