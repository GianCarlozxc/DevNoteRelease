# DevNote 1.1.1

New notes now start with a blank note name instead of a prefilled Untitled title. This applies to New Note buttons, the sidebar right-click menu, and Ctrl+N. Existing note titles remain unchanged.

If you are using DevNote 1.1.0, open Settings, choose Check for updates, download 1.1.1, then Restart to update. Unsaved drafts are saved before restarting.

Downloads include the Windows x64 installer, portable ZIP, checksums, and updater metadata. Version 1.0.0 users need to install the new installer once to enable in-app updates. Your notes and settings are preserved. This release is not digitally signed.

Source: https://github.com/GianCarlozxc/DevNote (private).

Validation: packaged desktop flow and the live GitHub update feed.
